# Window Atlas — 日本語ガイド

**ウィンドウを配置し、いつもの場所を記憶する** GNOME Shell拡張です。Spectacle風のキーボード配置に、アプリ再起動後も使える位置記憶・復元を組み合わせています。

## 導入

```bash
git clone https://github.com/tanabe1478/window-atlas.git
cd window-atlas
python3 tools/manage.py validate
python3 tools/manage.py doctor
python3 tools/manage.py install
```

sudoは不要です。作業を保存してログアウト→ログインした後:

```bash
gnome-extensions enable window-atlas@tanabe1478
gnome-extensions prefs window-atlas@tanabe1478
```

「拡張機能」アプリでユーザー拡張が全体で無効になっている場合は有効にしてください。インストーラーはファイルを配置するだけで、既存の設定・キー・拡張の有効無効は変更しません。

対象はGNOME 45～50。実行テスト環境はUbuntu 26.04.1 / GNOME 50.1 / Waylandです。KDE、Xfce、Swayには対応しません。

## 配置操作

初期修飾キーは **Super + Ctrl + Alt**（SCA）。

- SCA + 矢印: 上下左右の半分。繰り返すと1/2 → 2/3 → 1/3。
- SCA + Shift + ← / →: 左上／右上。SCA + Shift + ↓ / ↑: 左下／右下。
- 四隅は高さを半分に保ち、繰り返すと幅だけ1/2 → 2/3 → 1/3。
- SCA + `.` / `,`: 次／前の1/3領域。横3領域→縦3領域の順で巡回。
- SCA + F / C: 最大化／中央配置。
- SCA + `=` / `-`: 拡大／縮小。初期値30論理px、画面端への接触を維持。
- SCA + PageUp / PageDown: 前／次のディスプレイ。
- SCA + Z / Shift + Z: Undo／Redo。
- SCA + R: このログインセッションで最初に操作した直前の状態へ戻す。一時的な履歴であり、永続記憶とは別です。

設定画面からキー表示を押すと編集できます。Escでキャンセル、Backspace/Deleteで解除。本家キーに近い「Spectacle配列」も選べますが、GNOME標準のワークスペースキー等と競合するため、適用前の警告を確認してください。OS側のキーを自動解除しません。

## 位置の記憶・復元

- **SCA + S**: このウィンドウの位置・サイズ・モニターを記憶。
- **SCA + L**: 記憶した位置へ復元。復元操作もUndoできます。
- パネルメニューの「位置の記憶・復元」から全ウィンドウの記憶・復元も実行できます。

### 最後の位置を覚える

「移動・サイズ変更時に位置を自動記憶」は初期値で有効です。普段の移動やドラッグによるリサイズも記録します。

次回起動時にも自動復元するには、設定で **「新しく開いたウィンドウを記憶した位置へ復元」** を有効にしてください。突然ウィンドウが移動しないよう、自動復元の初期値は無効です。既に開いているウィンドウを一斉に動かす機能ではありません。

### 固定レイアウトを保存する

1. 「移動・サイズ変更時に位置を自動記憶」を無効にする。
2. ウィンドウを好みの位置へ配置する。
3. メニューから「全ウィンドウの配置を記憶」を実行する。
4. 別の配置に動かしても、メニューの「開いているウィンドウの配置を復元」で戻せる。

自動記憶が有効なままだと、後の移動で保存位置も更新されます。記憶と自動復元は独立した設定なので、自動記憶を無効にし、自動復元だけを有効にする使い方もできます。

## データと制約

保存先は通常 `~/.config/window-atlas/positions.json`。アプリ識別子と位置・サイズ・モニターのみを保存し、タイトルや文書パスは保存しません。ディレクトリ権限0700、ファイル0600、ネットワーク送信なしです。

同じアプリの複数ウィンドウは開いた順で対応します。個々の文書を識別する機能ではありません。開く順が違えば復元先も入れ替わることがあります。閉じたアプリや文書を起動する機能ではありません。

モニターが外れていれば、現在の画面内に収めます。新しいMutterではコネクター名を使い、古いGNOMEでは画面座標・サイズによる代替識別を使います。詳細は [位置記憶の仕様](position-memory.md) と [Spectacleとの対応](compatibility.md) を参照してください。

通常のアプリウィンドウが対象です。全画面表示中は操作せず、アプリの最小サイズ・固定サイズ・端末の文字単位サイズ等を優先します。

## 削除・トラブルシューティング

記憶した位置だけを消す場合は、設定画面の「記憶したすべての位置を削除」から確認付きで削除します。現在のウィンドウ配置やショートカットは変更しません。

```bash
python3 tools/manage.py doctor
gnome-extensions info window-atlas@tanabe1478
journalctl --user -b -o cat | grep -Ei 'Window Atlas|window-atlas|JS ERROR'
```

「拡張機能が存在しない」は、インストール先とログインし直しを確認してください。キーだけ動かない場合は、パネルメニューで比較し、他の拡張やOSとのキー競合を確認してください。

アンインストール:

```bash
gnome-extensions disable window-atlas@tanabe1478
python3 tools/manage.py uninstall
```

保存設定・位置記憶は残します。削除する場合は先に設定画面で位置記憶を削除してください。
